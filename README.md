
# Student Management System

## Project Description
A console-based Student Management System developed using C programming.

This project helps manage student records through a simple menu-driven interface.

## Features
- Add student records
- View all students
- Search students by roll number
- Update student details
- Delete student records
- Save and load records using file handling

## Concepts Used
- Structures
- Arrays
- Functions
- Loops and conditional statements
- Switch-case
- Pointers and file handling concepts
- File operations

## Technologies
- Language: C
- Editor: Visual Studio Code
- Compiler: GCC

## How to Run

Compile:
gcc main.c -o main.exe

Run:
.\main.exe
